# Gryph ClubConnect UI Portfolio

A small frontend-only portfolio project showing three interfaces from the Gryph ClubConnect design work. This is not the complete application or a live campus service.

- **Explore Clubs:** directory cards, filters and example membership states.
- **Student Dashboard:** upcoming events, tasks, announcements and club activity.
- **Club Workspace:** an executive's view of club operations.

The gallery navigation is interactive; the product controls within each preview are illustrative. Every club, person, venue and activity shown is fictional. There are no user accounts, forms that submit data, production integrations, analytics, automated workflows or environment variables. The original design components are included with synthetic fixtures and a standalone gallery.

## Run locally

Use Node.js 22.12+ (or 20.19+). From the project directory:

```sh
npm install
npm run dev
```

Open the local address printed by Vite. The previews maintain their desktop layout; narrow viewports can scroll the preview horizontally. Run `npm run build` to type-check and create the production bundle.
